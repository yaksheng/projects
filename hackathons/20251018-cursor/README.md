# Financial Wellness Platform

This hackathon project built a mobile financial wellness experience that combines financial education, habit building, and a virtual companion.

## Project Scope

- A virtual companion that changes as users progress
- Rewards for learning activities and financial milestones
- AI assisted financial education
- Goal and progress tracking
- Mobile first interaction design

## Product Direction

The experience makes financial learning feel approachable. Progress through lessons and milestones influences the companion, rewards, and the next recommended activity.

## Technology

The project documentation covers React, Vite, Tailwind CSS, Framer Motion, Three.js, Supabase, PostgreSQL, and Gemini.
