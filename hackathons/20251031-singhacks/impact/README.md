# Evaluation Framework

The evaluation framework measures whether conversational interfaces reduce friction in travel insurance discovery and claim intake.

## Evaluation Questions

- Can users identify suitable coverage more quickly?
- Do plain language explanations improve policy comprehension?
- Can structured claim intake reduce missing information?
- Which decisions require insurer or human review?
- How should accessibility and informed consent be evaluated?

## Measures

| Area | Measure |
| --- | --- |
| Task completion | Time and steps required to complete a defined flow |
| Comprehension | Accuracy on questions about coverage and exclusions |
| Claim intake | Completeness of submitted information |
| Accessibility | Results against a named accessibility standard |
| Escalation | Frequency and reason for human review |

These measures define how project outcomes are evaluated.
