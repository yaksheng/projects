# SingHacks Insurance Platform

A conversational, AI-powered travel insurance platform built for the SingHacks 2025 hackathon, sponsored by Ancileo and MSIG Asia.

## Overview

The SingHacks Insurance Platform transforms traditional travel insurance by integrating multi-modal conversational AI with micro-insurance solutions. Users can purchase insurance policies, file claims, and receive personalized recommendations through natural conversations in text, voice, or image formats.

## Key Highlights

- **Conversational Interface**: Natural language interactions across multiple modalities
- **SNACK Micro-Insurance**: Incremental coverage for specific travel needs
- **Multi-Agent AI System**: Intelligent orchestration of specialized AI agents
- **Real-time Recommendations**: Personalized policy suggestions based on user context
- **Seamless Claims Process**: Streamlined claim filing with document recognition

## Technology Stack

- **Frontend**: Next.js, React
- **Backend**: FastAPI, Python
- **AI Agents**: CrewAI, LLM orchestration
- **Database**: PostgreSQL/Supabase
- **Caching**: Redis
- **Multi-modal Processing**: Speech-to-text, OCR, image recognition

## Mission

To make travel insurance accessible, personalized, and stress-free through conversational AI, ensuring users get the right coverage when and where they need it.
