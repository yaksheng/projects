# SingHacks Travel Insurance Platform

This SingHacks 2025 project built a conversational travel insurance prototype spanning text, voice, images, and documents.

## Project Scope

- Conversational policy discovery
- Plain language coverage explanations
- Structured claim intake
- Document and image collection
- Routing to insurer, payment, and support workflows
