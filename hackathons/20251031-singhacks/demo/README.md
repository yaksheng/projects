## Video Demo Guide

### Setup Requirements

- Modern web browser (Chrome/Firefox/Safari)
- Microphone for voice demonstration
- Camera for image/document capture
- Stripe test card for payment simulation

### Demo Flow

1. **Introduction (30 sec)**
   - Brief overview of the platform
   - Show the conversational interface

2. **Core Features (3 min)**
   - Text conversation for policy purchase
   - Voice interaction demonstration
   - SNACK micro-insurance selection
   - Multi-modal document processing

3. **Claims Process (2 min)**
   - Initiate a sample claim
   - Document upload and AI validation
   - Instant claim approval simulation

4. **Personalization (1 min)**
   - Show how recommendations adapt to user profile
   - Demonstrate context retention

5. **Q&A (1.5 min)**
   - Open for questions
   - Highlight key differentiators
