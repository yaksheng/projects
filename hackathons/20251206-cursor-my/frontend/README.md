# Frontend Design

The frontend design guides users from a product brief through design review, refinement, file download, and order planning.

## Screens

- Product brief upload
- Design overview and three dimensional preview
- Refinement request
- Generated file review and download
- Order flow

## Components

- Design viewer
- Workflow action controls
- File download controls
- Client state for refinement progress
- Convex client for backend communication

## Technology

The project documentation covers Next.js, TypeScript, Zustand, Tailwind CSS, Convex, and an STL viewer.
