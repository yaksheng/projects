# Visualization

SourceVoice's visualization capabilities provide clear, actionable insights through AI-generated images and interactive cost breakdowns, helping users understand complex injection molding concepts and make informed decisions.

## Core Capabilities

### AI-Generated Mold Visualizations
- **3D Mold Renderings**: Detailed visualizations of injection molds based on specifications
- **Customizable Views**: Different angles and cross-sections of mold designs
- **Material Visualization**: Representation of different plastic materials and their properties
- **Mold Component Breakdown**: Individual parts labeled for better understanding

### Cost Analysis Visualizations
- **Interactive Cost Breakdowns**: Detailed pie charts and graphs of manufacturing costs
- **Material Cost Projections**: Visual representation of material price impacts
- **Tooling Cost Analysis**: Clear breakdown of mold creation and maintenance costs
- **Comparison Charts**: Side-by-side comparison of different manufacturing scenarios

### Real-time Updates
- **Dynamic Visualizations**: Updates as negotiation parameters change
- **Responsive Design**: Adapts to different screen sizes and devices
- **Export Capabilities**: Download images and charts for documentation
- **Shareable Views**: Generate links to share visualizations with team members

## Technical Implementation

### AI Image Generation

The visualization feature leverages advanced generative AI technology to create detailed technical images:

1. **Specification Processing**: Takes mold specifications and transforms them into a structured prompt
2. **AI Generation**: Uses Google Generative AI to create professional technical drawings
3. **Image Optimization**: Processes generated images for clarity and technical accuracy
4. **Display Integration**: Seamlessly presents images within the negotiation workflow

The system generates high-quality technical drawings that include dimensions, component labels, and cross-sectional views to facilitate better communication with suppliers.

### Cost Visualization Component

The cost visualization component presents detailed breakdowns of manufacturing costs using interactive charts:

- **Pie Charts**: Visual representation of cost distribution across material, tooling, labor, and overhead
- **Responsive Design**: Adapts to different screen sizes for optimal viewing
- **Interactive Elements**: Hover tooltips with precise cost values
- **Color Coding**: Consistent color scheme for different cost categories

### Visualization State Management

The visualization system uses a centralized state management approach to:

- Track current visualization type (mold, cost, or comparison)
- Manage mold specifications and parameters
- Store cost breakdown data for chart generation
- Handle user interactions with visualization elements
- Maintain visualization preferences across sessions
