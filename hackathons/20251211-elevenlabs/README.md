# SourceVoice

SourceVoice is a hackathon project for voice assisted English and Mandarin negotiation in injection molding procurement.

## Project Scope

- Voice and text interaction
- Manufacturing questions and negotiation guidance
- Cost breakdowns
- English and Mandarin support
- Generated visual references

## User Flow

1. Describe a component and procurement context.
2. Ask manufacturing and pricing questions by voice or text.
3. Review a cost breakdown and negotiation considerations.
4. Generate visual references for discussion with suppliers.
5. Continue the conversation in English or Mandarin.

## Technology

The project documentation covers Next.js, React, TypeScript, Tailwind CSS, Zustand, Claude, Gemini, ElevenLabs, and the Web Speech API.
